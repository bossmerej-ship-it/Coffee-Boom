# Coffee Boom Astana (Samal 12 Branch) — Web Development Project

A multi-page, semantic HTML5 website developed as a coursework assignment for the Web Technologies / Frontend Development course. The website serves as an informational portal for the local branch of the **Coffee Boom** chain located at **Samal microdistrict, 12, Astana**.

---

## 👥 Project Authors & Division of Work

This project was built collaboratively by a two-student team:

* **Merey Kuatbay**
  * `index.html` — Homepage, brand overview, mission, and general contact details.
  * `menu.html` — Authentic beverage and pastry price list with semantic data table structures.
  * `order.html` — Online pre-order workflow with complex HTML form controls and validation constraints.

* **Timur Naumov**
  * `about.html` — In-depth profile of the Samal 12 branch, seating capacity, and hall specifications.
  * `feedback.html` — Guest experience review page with full feedback questionnaire form.
  * `colophon.html` — Technical report, validator outcomes, accessibility self-audit, and asset licensing.
